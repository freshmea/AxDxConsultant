# Pyramid Program

## 개요
사용자로부터 숫자를 입력받아 피라미드 형태의 별(*)을 출력하는 프로그램입니다.

## 사용 방법
```bash
python test.py
```

실행 후 피라미드 높이를 숫자로 입력하면 됩니다.

## 실행 예시
높이를 5로 입력:
```
    *
   ***
  *****
 *******
*********
```

## 코드 설명
- `input()`: 사용자로부터 높이를 입력받음
- `range(1, height + 1)`: 1부터 높이까지 반복
- `" " * (height - i)`: 왼쪽 공백 출력 (정렬용)
- `"*" * (2 * i - 1)`: 별 출력 (줄마다 1, 3, 5, ... 개씩 증가
