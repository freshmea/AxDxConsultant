# 2026-04-27 DXAX 수업 한페이지 요약

## 수업 전체 요약
이번 수업은 4주차를 시작하며, 금요일에 다뤘던 `이미지 생성`을 다시 짚은 뒤 그것이 `동영상 생성`으로 어떻게 확장되는지를 설명한 날이었다. 수업 초반에는 지난 시간 흐름을 짧게 복습하면서, 생성형 AI를 업무에 붙일 때는 여전히 프롬프트와 컨텍스트 설계가 중요하지만, 이제는 정적인 이미지에서 멈추지 않고 움직이는 미디어까지 AX 워크플로우에 포함할 수 있다는 점을 강조했다. 즉, 이번 날의 핵심은 새로운 주제를 갑자기 여는 것이 아니라, 금요일 이미지 생성 파트의 자연스러운 다음 단계로서 영상 생성의 구조와 활용 맥락을 이해하는 것이었다.

수업 중반부터는 과거 영상 제작 방식과 AI 영상 생성의 차이를 본격적으로 설명했다. 기존 영상 제작은 스튜디오, 배우, 로케이션, 촬영, 편집 등 많은 비용과 시간이 드는 과정이었고, 한 번 찍은 뒤에는 재촬영이나 수정도 부담이 컸다. 반면 AX 워크플로우 안에서 영상 생성을 바라보면 텍스트 기획이나 초기 이미지에서 바로 비디오를 만들 수 있고, 결과를 본 뒤 파라미터를 조정하며 반복 실험할 수 있다는 점이 큰 변화로 제시됐다. 다만 이 방식도 만능은 아니며, 생성 시간과 비용이 여전히 크고 로컬 실행 시 하드웨어 제약이 상당하다는 현실적 한계도 함께 짚었다.

오후 후반의 중심은 실제 비디오 생성 구조와 도구 비교였다. 영상 생성은 크게 `text-to-video`, `image-to-video`, `video-to-video` 세 가지로 나눠 볼 수 있고, 현재의 주요 모델들도 기본적으로는 이미지 생성에서 보던 디퓨전 계열 원리의 확장선상에 있다는 설명이 이어졌다. LTX Video, Runway 계열 서비스, Google/Gemini 쪽 영상 생성, 한때 많이 언급됐던 Sora 사례까지 언급하며 상용 서비스와 오픈소스 흐름을 비교했고, 특히 LTX 같은 오픈소스 모델은 로컬 혹은 서버 환경에서 반복 생성이 가능하다는 점 때문에 교육용 실습 대상으로 다뤄졌다. 이어서 VRAM 요구량, 프레임, 해상도, 업스케일링, 생성 속도 같은 실무 조건과 함께, AI 영상이 마케팅 숏폼, 대량 개인화 비디오, 내부 커뮤니케이션 영상 제작에서 어떤 가치를 만드는지 정리했다.

## 무엇을 배웠나
- 금요일의 이미지 생성 학습이 월요일의 동영상 생성 학습으로 자연스럽게 이어진다는 전체 흐름을 이해했다.
- 영상 생성은 기존 제작 방식처럼 촬영 중심이 아니라, 텍스트나 초기 이미지에서 바로 결과를 만들 수 있는 새로운 제작 방식이라는 점을 배웠다.
- 전통적인 영상 제작은 비용, 시간, 재촬영 부담이 큰 반면 AI 영상 생성은 반복 수정과 빠른 실험에 강점이 있다는 점을 이해했다.
- 동영상 생성은 `text-to-video`, `image-to-video`, `video-to-video` 세 가지 대표 방식으로 구분할 수 있다는 점을 배웠다.
- 현재 영상 생성 모델도 본질적으로는 이미지 생성과 닿아 있는 디퓨전 계열 확장이라는 점을 이해했다.
- LTX Video는 비교적 가벼운 오픈소스 비디오 모델로 소개됐고, 로컬 또는 서버 환경에서 실습 가능한 흐름이라는 점을 배웠다.
- Runway, Google/Gemini 계열 서비스, 과거 Sora 언급까지 포함해 상용형 서비스와 오픈소스형 접근 방식을 비교했다.
- 로컬 실행에서는 VRAM 요구량이 높아 노트북 환경만으로는 한계가 있을 수 있고, 서버 환경이 필요한 경우가 많다는 점을 확인했다.
- 영상 생성은 해상도보다 먼저 결과를 뽑고 나중에 업스케일링하는 접근이 더 실용적일 수 있다는 점을 배웠다.
- AI 영상은 마케팅 숏폼 제작에서 빠른 대응력을 높이고, 고객별 맞춤형 비디오를 대량 생산하는 데 유리하다는 점을 이해했다.
- 사내 교육, 안전 가이드, 내부 공지 같은 텍스트 중심 메시지를 영상으로 바꿔 전달력을 높일 수 있다는 실무 사례를 배웠다.
- 결국 영상 생성도 이미지 생성과 마찬가지로 `기획 → 생성 → 수정 → 재생성`의 반복 워크플로우로 운영해야 한다는 점을 확인했다.

## 핵심 메시지
- 이번 수업의 핵심은 이미지 생성에서 끝나지 않고, 그 다음 단계인 영상 생성까지 AX 흐름을 확장해서 보는 관점을 갖는 것이었다.
- AI 영상은 전통적인 영상 제작을 완전히 대체한다기보다, 빠른 실험과 반복 수정이 가능한 새로운 제작 레이어로 이해해야 한다.
- 동영상 생성은 기술 데모가 아니라 마케팅, 개인화, 내부 커뮤니케이션 같은 업무 영역에서 바로 가치가 생기는 도구다.
- 영상 생성의 품질은 모델 이름보다도 기획 의도, 입력 방식, 반복 수정 전략, 실행 환경에 크게 좌우된다.

## 기억해야 할 디테일
- 영상 생성 입력은 크게 텍스트, 초기 이미지, 기존 영상 세 가지 축으로 나뉜다.
- 현재의 비디오 생성도 이미지 생성과 비슷한 디퓨전 기반 원리를 바탕으로 움직임을 확장하는 구조로 이해하면 된다.
- LTX 같은 오픈소스 모델은 로컬 실행 가능성이 있지만 VRAM 요구량과 생성 시간이 현실적인 제약이 된다.
- 해상도와 프레임을 무조건 높게 잡기보다 먼저 생성 후 업스케일링하는 방식이 실용적일 수 있다.
- 영상 생성은 반복 수정이 가능하지만 그만큼 생성 시간과 비용도 계속 발생한다는 점을 같이 봐야 한다.
- AI 영상의 실무 강점은 빠른 대응, 대량 개인화, 내부 전달력 강화 세 가지로 요약할 수 있다.
- 이미지 생성에서 만든 콘셉트 자산은 이후 영상 생성의 초기 입력이나 기획 베이스로 이어질 수 있다.

## 결론
2026년 4월 27일 수업은 금요일의 이미지 생성 학습을 발판으로, 그 다음 단계인 동영상 생성이 AX 워크플로우에서 어떤 의미를 가지는지 설명한 시간이었다. 핵심은 AI가 정적인 시각 자료를 만드는 수준을 넘어, 움직이는 미디어까지 빠르게 기획하고 반복 수정할 수 있는 생산 체계로 확장되고 있다는 점이다. 따라서 이 날의 메시지는 `이미지 생성 → 영상 생성 → 업무형 콘텐츠 제작`으로 이어지는 흐름을 이해하고, 그 안에서 비용·속도·품질·하드웨어 제약을 현실적으로 판단하는 것이었다.
